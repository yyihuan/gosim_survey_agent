# v4 observing gaps

本页只维护模拟对现实的外推边界。比赛规则、参数、消息和未决官方政策统一见[规则协议](v4-rules-and-protocol.md)，不要在此另抄计分表。已确认行为来自当前公开源码，不代表云端部署已经复验，也不把真实观测需求自行加入比赛评分器。

![一次观测的协议边界](diagrams/v4-protocol-sequence.svg)

| 问题 | 当前v4模型 | 外推时的限制 |
| --- | --- | --- |
| 深度累积 | 每源只取最佳有效单次；最大g另记 | 多次短曝不能当作合并信号的深曝光 |
| 亮度与质量 | fTQ标量完成因子，类别无额外响应 | 不是逐波长噪声、光谱线或红移成功率模型 |
| 天空与仪器 | 透过率、天空质量、seeing、效率的标量代理 | 不等同完整曝光时间计算器；亮源饱和和读噪没有独立建模 |
| 光纤分配 | 方格一格一源，起点几何命中后理想跟踪 | 不是带机械巡逻、碰撞、死纤的真实定位系统 |
| 定标资源 | 无专门校准动作或保留纤维配额 | 不据此推出实际巡天可以全部纤维观测科学目标 |
| 切换成本 | observe只按曝光时长推进模拟时间 | 没有独立转向、读出和重配置时间，频繁换场的结果不能直接外推 |
| 观测控制 | 动作内无取消接口，关闭片段仍消耗时间 | 不代表实际设备没有监控、联锁或紧急停止 |
| 最低高度 | 每源整段检查公开最低高度 | 不能推广为所有望远镜固定30度或同一机械限位 |
| 天气知识 | 公告粗方向、预报夜粒度，隐藏真值 | 无notice不等于晴好，不能把公开L卡truth变成Agent未来信息 |
| 质量反馈 | hits只有目标与含倍率贡献 | g/Q/B反推不唯一，饱和源不能提供唯一质量估计 |
| 限时任务 | 有明确请求窗和计分门槛 | 没有通用cadence、周期重访或成组依赖机制 |
| 维修 | report一步判断并修复当前仪器故障 | 没有独立维修时长和多类型维修操作 |
| 数据恢复 | resync撤销编号区间并重算 | 不返回精确g；模拟规则不是现实备份/质控工具 |
| 覆盖 | 目录目标在RA条带上的完成比例 | 不等同面积、深度选择函数或全天球像素完整度 |
| 时钟 | 模拟由动作推进，真实时间限制计算 | 策略思考时天体不自行移动；与真实望远镜同步调度不同 |
