# Experiment history

截至2026-10-03。本页是讨论与证据导航，完整数字以链接的原始记录为准；不同协议、卡片和代码版本不混作一组结论。

## v4 第一批：T/D/G/C/P/W

固定官方提交 `18be105`，建立隔离运行器与评分证据，依次做单项、选择性迭代、组合和冻结保留集。完整过程见 [策略报告 R1–R5](v4-strategy-study-report.md)、[84条记录](../experiments/v4/results/all_runs.json)、[数据分组](../experiments/v4/DATA_SPLIT.md)与[当时契约](../experiments/v4/EXPERIMENT_CONTRACT.md)。

六个问题分别为：曝光跨格承诺T、深度与广度D、观测几何G、覆盖代理C、候选选场P、粗预报避险W。

已支持的认识：严格短曝光可以增加科学分却因多漏必做而损失总分；曝光必须保护单次完成门槛。D线性代理是有价值的简单共同参照。更高高度、更宽搜索或更均匀的局部覆盖不能自动保证整季收益。W的固定方向降权在两张开发卡均退步。组合的收益不能把单项增量相加，开发领先的DTGP在保留集没有保持领先。

26次冻结保留评测均完整结束，但全部总分为负、必做缺口仍大。相对改善不等于任务规划可靠，也没有证明已经接近最优。

## v4 第二批：H/E/Q/M/F/J

仍使用同一旧评分环境，以D为共同底座。问题为剩余机会H、临界曝光E、质量余量Q、科学边际M、联合选场F、覆盖边际J。完整定义、参数和负结果见 [报告 N2–N5](v4-strategy-study-report.md)，原始材料为[97条新登记](../experiments/v4/extension/results/all_runs.json)、[冻结方案](../experiments/v4/extension/evaluation/N5_PLAN.json)。97条中78条为研究评估，19条为包装/迁移验收；不能当作97个独立样本。

E在开发阶段较弱，四张新卡却都优于D；FE在这四个样本中的平均增量最高，主要来自减少必做遗漏。Q单项与加入组合的结果没有支持可靠保护机制。H初版未改变轨迹，J改善子指标也可能挤掉其他任务。所有N5总分仍负。保留D、E、FE、旧DTGP作下一轮参照；负结果与代码同样保留。

下一步讨论集中于机制诊断：E/FE是否减少达标后的多余曝光、增加单次跨门槛完成、或改变选场顺序；required剩余工作量、截止与时间预算如何耦合；质量反馈应按曝光聚合，检查相关性与选择偏差后再校准。四张已揭示的保留卡不继续作为未见测试集。

## 程序与 LLM：已讨论设计，尚未验证收益

[协作设计](v4-llm-collaboration.md)提议先做异常诊断中的行动选择，再做任务冲突中的阶段规划。程序计算几何、候选、光纤与曝光，LLM读取有编号的证据和不同动机的候选，提出有期限的建议；程序核验并在超时、过期或非法时重新计算回退。

尚未实现统一证据包、主动探测选择、计划有效期和新的模型对照实验。已知公式可直接算，复杂取舍本身不是模型胜过程序的证据。不能用两个形式上的模型接口证明效果或评奖合规。拟议对照需程序增强、单独LLM诊断、单独LLM规划和联合接入，以及新的冻结数据分组。

规则台账也区分现实观测与模拟：当前单源结算取最佳单次贡献，多次短曝不能累加深度；共同曝光、反馈可观测性和未计入的现实开销限制外推。精确问题以 [规则台账](v4-rules-and-protocol.md)为准。
